# PhoneAgent 📱🤖

An Android AI agent that controls your phone using Grok AI vision.

## Install
1. Download `PhoneAgent-debug-APK` from [Actions](../../actions)
2. Enable "Install from unknown sources" on your phone
3. Install the APK
4. Follow the setup wizard

## First-Time Setup
1. Paste your Grok API key (get it at console.x.ai)
2. Enable Accessibility Service when prompted
3. Allow Screen Capture when you run your first task

## Usage
Just type what you want done:
- "Open Instagram and like the latest post from @username"
- "Open WhatsApp and send 'On my way!' to Mom"
- "Set my phone brightness to 50%"
- "Open YouTube and search for lo-fi music"

## Safety
- All data stored locally on your phone
- You can block specific apps in Safety Settings
- Emergency stop button always visible when agent is running
